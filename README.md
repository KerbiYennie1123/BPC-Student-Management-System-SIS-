# BPC Student Information System

The **BPC Student Information System (BPC SIS)** is a desktop application developed for Bulacan Polytechnic College. It aims to make managing student records, enrollment, academic information, and faculty assignments easier and more organized.

## About the Project

This project was created to provide a simpler way of handling student and academic records. Instead of managing everything manually, the system brings important school information together in one application.

It also allows administrators to manage faculty members and assign subjects to specific courses, year levels, and sections. Faculty members can view their assigned subjects and the corresponding list of students.

## Project Goals

- Make student records easier to manage.
- Simplify student enrollment.
- Organize academic years, semesters, courses, and subjects.
- Make faculty and subject assignments easier to handle.
- Provide easier access to academic information.
- Reduce manual recordkeeping and duplicate records.

## Target Users

- **Administrators** – Manage student records, enrollment, academic setup, user accounts, and faculty assignments.
- **Faculty Members** – View assigned subjects, sections, and their corresponding student lists.

## Features

- Dashboard with student statistics
- Student record management
- Student enrollment management
- Academic year and semester setup
- Course and subject management
- Faculty account management
- Faculty subject assignments
- Student lists based on assigned subjects and sections
- Search and filtering
- Import and export functionality
